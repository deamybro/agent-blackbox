# Three-minute demo

1. **0:00 - Landing:** Explain that Agent BlackBox is a flight recorder and risk firewall. Point out simulation-only status.
2. **0:25 - Dashboard:** Launch the control plane and show persisted metrics and portfolio flight path.
3. **0:45 - Safe cycle:** Run a cycle. Open the new decision and show agent reasoning, eight signal sources, 15 checks, verdict, and outcome.
4. **1:35 - Stress test:** Trigger dangerous ETH leverage. Show the firewall blocking 50x leverage, oversized exposure, missing stop, crisis conditions, and bad confidence.
5. **2:10 - Audit:** Filter the audit ledger and open the raw event.
6. **2:35 - Reports and SDK:** Export JSON/CSV, show summary evidence, then show how another agent integrates.
7. **2:55 - Close:** No live trade happened; Agent BlackBox made the autonomous loop observable and controlled.
